# 26 · 测试环境与端到端测试

> 版本：v1.3 · 2026-11-10（M0 前契约收口）
> 目的：核心业务测试不依赖真实模型 API；用 Mock 与故障注入验证状态机、真值表、幂等与恢复。
> 关联：07、13、21、24。

---

## 1. 环境组成

| 组件 | 实现 |
|---|---|
| PostgreSQL + pgvector | 测试库每次从空库迁移初始化 |
| Mock Chat Provider | 按角色返回固定/可编排 JSON，可模拟超时、非法 JSON、截断 |
| Mock Embedding | 固定维度向量，确定性 |
| Mock Reranker | 固定排序或按规则返回 |
| Worker 控制 | 可暂停、杀进程、模拟租约过期 |
| 时钟 | 可注入，测试超时/租约不靠 sleep |

## 2. 必测场景

| 类别 | 用例 |
|---|---|
| 真值表 | 3/3、2/3、1/3、0/3；accept/reject/uncertain/not_assessed 组合；blocker 判定 |
| 证据 | claim 聚合、partially_grounded blocker、冲突转人工 |
| 融合 | 正/负/边界样本；错误合并率 |
| 幂等 | 单条与批次重复提交、force、force_all |
| 并发 | 双 Worker 抢同一任务、旧 Worker 被 fencing 拒绝 |
| 恢复 | 投票阶段崩溃、租约过期、从 Checkpoint 继续 |
| 输出 | 非法 JSON、截断、额外字段、越权指令、ai_verdict 注入 |
| 权限 | 角色越权、X-Role 伪造、审批人=提交人 |
| 契约 | report Schema、Rubric Schema、迁移前后兼容 |

## 3. 分层测试

- **单元**：`verdict.py` 直接输入投票组合断言结果，不调用模型。
- **集成**：Mock 模型跑完整流水线，断言状态、报告、投影一致。
- **故障注入**：超时、429、断连、Worker 崩溃、DB 事务失败。
- **迁移**：空库 → 最新；旧版本库 → 最新；回滚一次。
- **端到端**：固定冻结集 + Mock/真实模型两套；真实模型只做验收，不跑日常 CI。

## 4. CI 门禁

```
1. 迁移与 Schema 校验
2. 单元 + 集成 + 故障注入
3. 真值表/融合/权限/幂等测试
4. 文档-契约一致性（docs/17、rubric、report schema）
5. 报告 Schema 兼容性
6. 性能冒烟（不阻塞，记录）
```

任何一项失败阻断合并；真实模型测试单独流水线，按预算触发。
