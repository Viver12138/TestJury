# 25 · 知识解析与增量构建

> 版本：v1.12 · 2026-11-10（补充 20 落实：内容版本与构建版本）
> 目的：定义知识文件解析失败、切片质量、增量构建与版本隔离的规则。
> 关联：11、16、02 `kb_*`。

---

## 1. 解析质量门禁

| 检查 | 不通过处理 |
|---|---|
| YAML front matter 合法 | 阻断发布 |
| 必填元数据（doc_id/module/doc_type/source_ref） | 阻断发布 |
| RULE-ID 唯一、非空 | 阻断发布 |
| 规则正文非空 | 阻断发布 |
| Markdown 表格/代码块未被切片破坏 | 阻断发布 |
| 切片 `heading_path` 可回溯 | 阻断发布 |
| 原子语义完整（一条规则不被拆成两个 chunk） | 阻断发布 |
| Embedding 全部成功 | 阻断发布 |
| 检索回归达标 | 阻断发布 |

解析失败的文件进入 `failed`，不进入 active 版本；修复后重新构建。

## 2. 内容哈希与增量

<!-- §1 的实现补充见文末 §6；离线候选不属于 active 构建。 -->

- `content_hash = sha256(规范化正文 + 元数据 + source_version)`。
- 发布时对比上一 active 版本：
  - 新增 → 解析 + 切片 + 向量化；
  - 修改（hash 变）→ 重新解析该文档并替换其 chunks；
  - 未变 → 复用旧 chunks/向量（同 embedding profile）；
  - 删除 → 新版本中不包含该文档，旧版本保留。
- 不允许"只增不删"导致已删除规则仍被召回。

## 3. 版本隔离

- 每个 `kb_version` 有完整逻辑视图（文档、规则、chunks、索引）。
- 评审任务创建时冻结 `kb_version`；旧版本在仍有任务引用时不得物理删除。
- active 切换在事务内完成：旧 active → retired，新版本 → active；切换期间新任务用新版本，旧任务继续用旧版本。
- 索引重建用新表/别名切换，不做"先删后建"。
- **内容版本 vs 构建版本**：内容哈希只决定是否需要重新解析；解析器、切片规则、索引构建规则变化时，即使内容不变也必须生成新的 `kb_build_version` 并重建索引。历史报告保留原 `kb_content_version` + `kb_build_version` + `chunk_id`，旧构建不覆盖（`docs/11` §9）。

## 4. 知识问题分型

`kb_gaps` 不再统一叫"缺口"，按 `gap_type` 分型：

| 类型 | 根因 | 处理 |
|---|---|---|
| `knowledge_missing` | 确实没有规则 | 补知识 |
| `retrieval_missed` | 有规则未召回 | 修检索/索引 |
| `knowledge_conflict` | 规则冲突 | 人工裁决 |
| `knowledge_outdated` | 规则过期 | 更新/废弃 |

分型后才能分配正确责任人，避免"检索问题"被当成"知识缺失"重复录入。

## 5. 发布差异

每次发布生成差异报告：新增/修改/删除/废弃、受影响模块、检索指标、证据引用变化、冲突。详见 `docs/16` §6。

## 6. 首批离线实现边界（2026-11-12）

`scripts/check_kb.py` 检查三层：结构（严格 YAML、字段、枚举、ID、项目/模块映射）、证据（快照/commit/哈希/行号、受控决策与内部规范来源）、治理（四维状态、引用、已审核内容漂移）。正常检查允许真实的待办存在；`--release` 在待办未解除时返回失败，不能用正常检查通过宣称已发布。

`scripts/build_kb_candidate.py --baseline ... --source-root ... --output ...` 只构建离线候选：排除待复审或来源不完整的文档，保留完整规则/流程、Markdown 表格与代码块，输出文档/片段 ID、标题路径、来源、证据等级及内容/构建双版本。基线、解析器、契约或来源绑定变化会产生新的构建版本。构建不执行 MiniShop 代码，不调用供应商，不写数据库或切换 active。

Embedding、混合索引、检索/评审黄金集验收和权限控制发布尚未实现。候选产物固定标记 `unpublished`、`formal_admission=blocked`；运行时仍使用 `kb-none`，不能把离线片段当作已接入生产的检索结果。
