# 21 · 端到端验收标准

> 版本：v1.2 · 2026-11-10（契约一致性冻结修订）
> 目的：给出 v1 是否可以交付的统一门槛；指标必须有数据集、计算方式、样本量与波动范围，不能只写一个数字。
> 关联：07、12、15、20。

---

## 1. 验收维度与门槛

| 维度 | 指标 | 门槛（首版，压测/评测后校准） |
|---|---|---|
| 评审质量 | Blocker Recall（严格） | ≥ 70% |
| 评审质量 | High-risk Recall（人工 blocker+major 被报告为 blocker/major） | ≥ 80% |
| 评审质量 | Blocker Precision | ≥ 75% |
| 评审质量 | Blocker Detection Recall（辅助，blocker/major 命中） | 观察值 |
| 评审质量 | False Discovery Rate（FDR，FP/(TP+FP)） | ≤ 25% |
| 评审质量 | FPR（FP/(FP+TN)） | 需完整负样本，v1 不计算 |
| 评审质量 | False Negative Rate | ≤ 20% |
| 严重级 | Severity Accuracy（accepted 问题） | ≥ 75% |
| 证据 | Evidence Accuracy（claim 与证据匹配） | ≥ 90% |
| 融合 | False Merge Rate | ≤ 10% |
| 融合 | Incremental Valid Issue Rate（多模型增量） | 观察，实验后定 |
| 检索 | Recall@10 / nDCG@10 | ≥ 90% / ≥ 0.75 |
| 可靠性 | 任务成功率（3/3 或 2/3 正常完成） | ≥ 97% |
| 可靠性 | 恢复成功率（杀 Worker 后可恢复） | 100%（测试样本） |
| 性能 | P95 端到端（不含排队） | ≤ 20 分钟 |
| 性能 | P95 创建接口 | ≤ 300ms |
| 成本 | 单条平均成本 | ≤ 预算上限 |
| 成本 | Cost per Valid Issue | 观测，实验后定 |
| 增量 | Incremental Valid Issue Gain | 观测，实验后定 |
| 一致性 | 报告与 `issues` 投影一致率 | 100% |
| 安全 | 越权/注入测试通过率 | 100% |

> 数字是初始门槛；每季度用新数据重算，并在验收报告中记录样本量与置信区间。

## 2. 数据集要求

- 评审黄金集：≥ 30 份起（只够流程验证），正式验收建议扩到 ≥ 100 份并冻结。
- 检索黄金集：≥ 100 条查询，含 hard negative。
- 融合样本：正/负/边界各 ≥ 50 对。
- 证据样本：含 E1/E2/E3/E4、历史缺陷、冲突、缺失。
- 失败样本：超时、非法 JSON、截断、引用不存在、越权指令。
- 数据集分 dev / validation / frozen / regression；frozen 不参与调参。

## 3. 计算与记录

每个指标必须记录：

- 数据集版本、样本量；
- 计算脚本与版本；
- 分子/分母定义；
- 波动范围（bootstrap 置信区间或多次运行方差）；
- 失败样本清单。

缺少任一项的数字不能作为发布门槛。

## 4. 发布门禁

```
1. 检索回归达标
2. 融合回归达标（错误合并率 ≤ 10%）
3. 评审回归达标（blocker recall/precision）
4. 真值表测试全通过（docs/12）
5. 失败/恢复/幂等测试通过
6. 权限/注入测试通过
7. 成本与 P95 在预算内
8. 报告可读性验收通过（docs/07 §8.7）
→ 允许发布
```

任一不达标：阻断发布；修复后重跑全量，不允许"只跑改动部分"。

## 5. 验收报告

每次候选版本产出一份 `data/acceptance/<version>.json`：

```json
{
  "version": "v1.0-rc1",
  "dataset": "frozen-2026-12",
  "metrics": { "blocker_recall": 0.0, "precision": 0.0, "p95_ms": 0 },
  "gates": { "retrieval": "pass", "truth_table": "pass" },
  "waivers": [],
  "decision": "pass|fail"
}
```

## 6. 例外与豁免

- 任何豁免必须记录：指标、原因、影响范围、补偿措施、有效期、批准人。
- 不允许用"演示样例通过"替代冻结集评测。
- 不允许在被豁免的指标上宣称"已验证"。

## 7. 与模型组合实验的关系

- `docs/15` 回答"多模型是否值得"；本文回答"系统是否可以交付"。
- 两者共用冻结集与指标定义，但门槛不同：实验用于选型，验收用于发布。
