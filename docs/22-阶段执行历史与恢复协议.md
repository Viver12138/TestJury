# 22 · 阶段执行历史与恢复协议

> 版本：v0.8 · 2026-11-10（v0.8：跨文档冲突清理与 P0 决策冻结）
> 目的：把 Checkpoint 从"当前状态"升级为"可审计的执行历史 + 版本冻结的恢复协议"。
> 关联：02 `review_stages`、13、14。

---

## 1. 两张表

| 表 | 职责 |
|---|---|
| `review_stages` | 每个阶段**当前**状态（唯一） |
| `review_stage_attempts` | 每次执行尝试的历史（只追加） |

`review_stage_attempts`：

| 字段 | 说明 |
|---|---|
| `review_id` / `stage` / `attempt_no` | 定位一次尝试 |
| `status` | `running` / `succeeded` / `failed` / `skipped` |
| `input_digest` | 本次尝试依赖的输入摘要 |
| `output_ref` | 输出位置（`model_runs` / candidates / report） |
| `started_at` / `finished_at` | 时间 |
| `error_code` / `error_message` | 失败原因 |
| `worker_id` | 执行者 |
| `model_run_id` | 适用时关联具体调用 |
| `created_at` | 记录时间 |

> `review_stages` 的 `UNIQUE(review_id, stage)` 只保留当前态；历史在 attempts 表，不覆盖。

## 2. 版本冻结

同一 `generation` 创建时冻结以下版本，写入 `review_jobs`，恢复时只读：

```
kb_version / rubric_version / prompt_versions / model_config_version
retrieval_config_version / embedding_profile_id / reranker_profile_id
report_schema_version / input_hash / case_version / fallback_model_policy
```

- 恢复任务**不得**自动切换 active KB、Prompt、模型配置。
- 若版本已被删除（如 KB 回滚删除索引），任务失败为 `VERSION_UNAVAILABLE`，不静默用新版本。
- 需要新版本 → 新建 generation。

## 3. `input_digest`

必须覆盖该阶段真正依赖的全部输入，而不是只用例文本：

```
stage || case_digest || upstream_output_digest || prompt_version
|| model_config_version || kb_version || retrieval_config_version
|| embedding_profile_id || rubric_version || report_schema_version
```

- 摘要变化 → 不能复用旧输出；必须明确：新 generation / 重跑该阶段 / 拒绝恢复。
- 比较摘要只用于判断"能否复用"，不替代版本号。

## 4. 恢复协议

1. 领取过期任务，读 `review_jobs` 冻结版本。
2. 校验冻结版本仍可用；不可用 → `failed(VERSION_UNAVAILABLE)`。
3. 从 `review_stages` 找到最后 `succeeded` 的阶段。
4. 校验其 `input_digest` 与当前冻结版本一致；不一致 → 拒绝恢复或重跑该阶段（按配置）。
5. 从下一阶段继续；已成功阶段不重跑。
6. 每次新尝试写 `review_stage_attempts`，并更新 `review_stages` 当前态。
7. 写终稿前再次校验 `status`、`attempt`、`generation`、`locked_by`。

## 5. 超时预算

| 项 | 预算 |
|---|---|
| 阶段超时 | 单次执行，含该阶段内调用重试 |
| 并行阶段 | 按最长分支计，不累加 |
| 任务总超时 | 20 分钟，含阶段与重试，不含排队 |
| 排队时间 | 不计入任务总超时，单独统计 |
| 渲染 | 独立 30s 预算 |

阶段合计 690s，加 2 次重试余量接近 15 分钟；因此总超时定为 20 分钟，压测后校准。超时耗尽时保留 Checkpoint 与已完成输出，任务 `failed(TIMEOUT)`，不出正式 `ai_verdict`。

## 6. 禁止

- 用新 KB/Prompt 恢复旧 generation。
- 覆盖 `review_stages` 历史而不写 attempt。
- 已成功阶段因"重试方便"整体重跑。
- 超时后继续写终稿。
