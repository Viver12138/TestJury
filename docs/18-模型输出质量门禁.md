# 18 · 模型输出质量门禁

> 版本：v0.8 · 2026-11-10（v0.8：跨文档冲突清理与 P0 决策冻结）
> 目的：把"模型输出不合格"从模糊判断变成可执行门禁，明确哪些重试、哪些丢弃、哪些阻断 Verdict。
> 关联：05 §7、10 §7、12、17。

---

## 1. 校验顺序

每次模型返回（预处理/盲评/投票/仲裁）依次执行：

1. HTTP 与 `finish_reason` 检查；
2. JSON 严格解析；
3. Schema（必填、类型、结构）；
4. 枚举（按 `docs/17`）；
5. 引用有效性（`kb_refs`/`evidence_refs` 必须存在于本次证据包）；
6. 数值范围（`self_confidence`、`step_index`）；
7. 业务规则（blocker 证据、历史缺陷、`not_assessed` 不被当反对）；
8. 一致性（同一模型前后矛盾、claim 与证据不匹配、输出含额外指令）。

## 2. 错误分类与处理

| 错误 | 示例 | 处理 | 是否阻断 Verdict |
|---|---|---|---|
| `TRANSPORT` | 超时、5xx、连接失败 | 退避重试 2 次 | 失败后按角色失败 |
| `RATE_LIMIT` | 429/限流 | 延迟重试（进重试队列） | 失败后按角色失败 |
| `TRUNCATED` | `finish_reason=length`、JSON 不完整 | 重试 1 次（可降 max_tokens 重试） | 是 |
| `JSON_SYNTAX` | 非法 JSON | 重试 1 次 | 是 |
| `SCHEMA` | 缺必填、类型错 | 重试 1 次 | 是 |
| `ENUM` | 非法枚举值 | 该条判无效；不猜测 | 视影响 |
| `CITATION` | 引用不存在/不匹配 | 该条判无效依据 | 若为 blocker 则阻断 |
| `RULE` | blocker 无证据、历史缺陷当当前 | 降级或判无效 | 若为 blocker 则阻断 |
| `CONTRADICTION` | 同模型前后矛盾 | 标记 `inconsistent`，重试 1 次 | 是 |
| `EXTRA_FIELD` | 输出含未授权字段 | 丢弃该字段，其余保留 | 否（字段级） |
| `PROMPT_INJECTION` | 输出试图改变规则/权限/ verdict/角色 | 丢弃整份输出，重试 1 次；仍出现则角色失败 | 是 |
| `VERSION_MISMATCH` | 输出引用的 prompt/model 版本与任务不一致 | 判失败，不采用 | 是 |

## 3. 重试规则

- 同一调用最多重试 2 次；同阶段最多 2 次；同任务最多 3 次。
- 重试使用**相同 Prompt 与模型配置版本**；不得在重试中换模型或改 Prompt。
- 重试产生新的 `model_runs`（`attempt` 递增），旧的保留。
- 限流错误进入延迟重试，不计入"模型故障"；但总预算仍受限。
- 重试耗尽 → 该角色失败，按 `docs/13` 的故障矩阵处理。

## 4. 局部丢弃 vs 整体失败

**先判断范围，再决定丢弃粒度**：

- 未授权字段、多余解释、格式瑕疵 → **字段级丢弃**，不影响其余内容；
- 试图改变 System Prompt、评审规则、角色、权限、投票流程、`ai_verdict` → **整份输出作废**，按 `PROMPT_INJECTION` 处理；
- 两者不能混为一谈：不能因为多了一个字段就阻断整份报告，也不能把越权指令仅丢掉字段后继续使用。

| 范围 | 允许局部丢弃 | 说明 |
|---|---|---|
| 单条 issue | 是 | 无效条目丢弃并记 `parse_warnings`，其他条目继续 |
| 单次投票的某候选 | 是 | 记 `not_assessed`，不得伪造 |
| 整份盲评 | 否 | Schema/枚举大量失败 → 角色失败 |
| 仲裁输出 | 否 | 必须覆盖全部候选；缺失补 `need_human` |
| Verdict | 否 | 规则计算失败 → 阻断报告 |
| 越权指令 | 否 | 整份输出作废 |

## 5. 与 Verdict 的关系

- 输出校验失败且无法恢复的角色，不能计入有效参与数。
- `blocker` 若因引用/规则错误被判无效，不得进入 `ai_verdict`。
- 仲裁输出不合规：重试 1 次；仍不合规则 `ai_verdict=need_human`，不得给 `blocked/conditional`。
- 所有 `parse_warnings` 与错误码写入报告附录，不能静默。

## 6. 验收

- 每类错误都有对应测试样本（非法 JSON、截断、错误引用、越权指令）。
- 测试证明：错误不会静默修补、不会进入终稿、不会把失败当 `reject`。
- 错误码与 `docs/19` 一致。
