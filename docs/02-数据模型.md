# 02 · 数据模型

> 版本：v0.11 · 2026-11-10（最后一轮冻结候选）

数据库：PostgreSQL 15+，扩展 `pgvector`、`pgcrypto`、`pg_trgm`；中文分词 `zhparser` 为可选升级（见 `docs/11` §5），未安装时关键词检索以 trigram + 精确匹配为准。

## 1. 实体关系

```
batches 1 ── n review_jobs
review_jobs 1 ── n model_runs        （3 次盲评 + 3 次投票 + 1 次仲裁 + 可能的重试）
review_jobs 1 ── n review_stages     （阶段 Checkpoint，恢复用）
review_jobs 1 ── n case_attachments  （附件引用与指纹）
review_jobs 1 ── n review_candidates （融合产生的候选问题，仲裁前中间数据）
review_candidates 1 ── n issue_votes （每个模型对候选问题的投票事实）
review_jobs 1 ── n issues            （最终报告问题的只读投影）
issues 1 ── 1 issue_embeddings
review_candidates 1 ── 1 candidate_embeddings（按 profile 可多条）
issues 1 ── n human_feedback
review_jobs 1 ── n review_decisions  （人工决定，append-only）
review_jobs 1 ── n webhook_deliveries
review_jobs 1 ── 1 report_json       （JSON 为唯一结构化事实源）
review_jobs 0..1 ── 1 parent_review  （generation 历史链）
embedding_profiles 1 ── n kb_chunks / issue_embeddings / candidate_embeddings
kb_versions 1 ── n kb_documents / kb_rules / kb_chunks
kb_documents / kb_rules / kb_chunks  ──  被报告通过 kb_refs 引用（逻辑引用，不建外键）
kb_gaps  ──  由评审中的"无依据判断"聚合产生
audit_log ──  横切：审批、强制重跑、KB 发布、配置变更（不建外键，保留历史）
```

## 2. DDL

```sql
CREATE EXTENSION IF NOT EXISTS vector;
CREATE EXTENSION IF NOT EXISTS pgcrypto;
CREATE EXTENSION IF NOT EXISTS pg_trgm;
-- 中文分词（可选，需编译安装；安装后按 docs/11 §5 重建 search_vector）
-- CREATE EXTENSION IF NOT EXISTS zhparser;

-- ───────────── 批次 ─────────────
CREATE TABLE batches (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    status          TEXT NOT NULL DEFAULT 'queued',   -- queued|processing|completed|partially_completed|failed|cancelled
    total           INT  NOT NULL DEFAULT 0,
    done            INT  NOT NULL DEFAULT 0,
    failed          INT  NOT NULL DEFAULT 0,
    caller_id       TEXT,
    input_hash      TEXT,                            -- 批次输入（用例集合）指纹
    idempotency_key TEXT,                            -- 批次级幂等键
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now(),
    finished_at     TIMESTAMPTZ
);

CREATE UNIQUE INDEX uq_batches_idempotency
    ON batches (idempotency_key)
    WHERE idempotency_key IS NOT NULL;

-- ───────────── 评审任务（同时充当任务队列） ─────────────
CREATE TABLE review_jobs (
    id                  UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    batch_id            UUID REFERENCES batches(id),
    case_id             TEXT NOT NULL,
    case_title          TEXT,
    case_version        INT  NOT NULL DEFAULT 1,      -- 调用方业务版本号；内容指纹由 input_hash 负责
    module              TEXT,                        -- 规范化后的模块名；未命中知识库时仍记录原值
    status              TEXT NOT NULL DEFAULT 'queued', -- queued|processing|retrying|done|failed|completed_with_warnings
    stage               TEXT,                        -- input_check|preprocess|kb_retrieve|blind_review|fusion|vote|arbitration|verdict|render
    ai_verdict          TEXT,                        -- blocked|conditional|need_human（AI 结论，永不为 approved）
    human_status        TEXT NOT NULL DEFAULT 'pending', -- pending|approved|rejected|changes_requested（派生自 review_decisions）
    current_decision_id UUID,                        -- 最新一条人工决定（逻辑引用 review_decisions.id）
    degraded            BOOLEAN NOT NULL DEFAULT FALSE,
    degraded_reasons    JSONB NOT NULL DEFAULT '[]',  -- ["kb_module_missing","raw_text_unparsed","vector_unavailable"...]
    participants        JSONB NOT NULL DEFAULT '[]',  -- ["chief:qwen-max","jury_a:deepseek-flash",...]
    review_completeness JSONB,                        -- {"blind":"3/3","vote":"2/3","arbitration":"ok","stages_completed":[...]}
    input_quality       JSONB,                        -- 输入质量检查结果（见 docs/10 §7.1）
    timings             JSONB,                        -- {"queue_ms":...,"execution_ms":...,"model_call_ms":...}

    -- 评审上下文（见 03 §1）
    test_scope          JSONB,                        -- {feature_point, required_scenarios, related_case_ids, scope_version}
    automation_context  JSONB,                        -- {framework, supported_operations, state_query_capabilities,
                                                     --  data_setup_capabilities, limitations}

    -- 版本
    kb_version          TEXT,
    rubric_version      TEXT,
    prompt_versions     JSONB,                        -- {"chief_blind":"p-1a2b", ...}
    prompt_version_hash TEXT NOT NULL,                -- sha256(prompt_versions) 前 12 位
    retrieval_config_version TEXT,
    embedding_profile_id BIGINT,                      -- 逻辑引用 embedding_profiles（建表后统一加外键）
    reranker_profile_id BIGINT,                       -- 逻辑引用 reranker_profiles
    model_config_version TEXT,                        -- models.yaml 配置版本
    report_schema_version TEXT NOT NULL,              -- 报告 JSON 结构版本

    -- 输入与结果
    input_hash          TEXT NOT NULL,                -- 规范化输入哈希（见 §3 第 1 条）
    idempotency_key     TEXT NOT NULL,                -- input_hash + 各版本号的组合哈希
    generation          INT  NOT NULL DEFAULT 1,      -- 强制重跑代次
    parent_review_id    UUID REFERENCES review_jobs(id), -- generation 历史链：上一次评审
    superseded_by       UUID REFERENCES review_jobs(id), -- 被新代次取代时指向新记录
    request_payload     JSONB NOT NULL,               -- 原始请求体
    normalized_case     JSONB,                        -- 规范化后的用例（含预处理拆分的 steps）
    report_summary      JSONB,                        -- 报告摘要（列表/筛选用）
    report_json         JSONB,                        -- 完整报告（唯一结构化事实源）
    report_locked_at    TIMESTAMPTZ,                  -- 非空即报告不可变；更正需新 generation
    error               TEXT,                         -- 失败原因（人类可读）

    -- 成本
    total_cost_estimate NUMERIC(12,4),
    cost_currency       TEXT DEFAULT 'CNY',

    -- 队列控制（持久化队列 / 租约 / 重试）
    attempt_count       INT  NOT NULL DEFAULT 0,
    max_attempts        INT  NOT NULL DEFAULT 3,
    locked_by           TEXT,                         -- worker 标识
    locked_at           TIMESTAMPTZ,
    lease_expires_at    TIMESTAMPTZ,                  -- 租约到期，过期可被其他 worker 领取
    fencing_token       BIGINT NOT NULL DEFAULT 0,    -- 仅在首次领取/接管时递增；正常续租不变；写入必须校验
    last_error          TEXT,

    created_at          TIMESTAMPTZ NOT NULL DEFAULT now(),
    started_at          TIMESTAMPTZ,
    finished_at         TIMESTAMPTZ
);

-- 同一幂等键同一时刻只允许一个 active 代次；force=true 先把旧代次置 superseded_by 再插入新代次
CREATE UNIQUE INDEX uq_review_jobs_idempotency
    ON review_jobs (idempotency_key)
    WHERE superseded_by IS NULL;

CREATE INDEX idx_review_jobs_case    ON review_jobs (case_id, created_at DESC);
CREATE INDEX idx_review_jobs_module  ON review_jobs (module, created_at DESC);
CREATE INDEX idx_review_jobs_verdict ON review_jobs (ai_verdict, human_status, created_at DESC);
CREATE INDEX idx_review_jobs_batch   ON review_jobs (batch_id);

-- 队列领取：只扫可执行任务，避免全表扫描
CREATE INDEX idx_review_jobs_queue
    ON review_jobs (status, lease_expires_at, created_at)
    WHERE status IN ('queued', 'processing', 'retrying');

-- ───────────── 输入附件（v1 只存引用与指纹，不做 OCR） ─────────────
CREATE TABLE case_attachments (
    id           UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    review_id    UUID NOT NULL REFERENCES review_jobs(id) ON DELETE CASCADE,
    file_name    TEXT NOT NULL,
    mime_type    TEXT NOT NULL,
    size_bytes   BIGINT NOT NULL,
    sha256       TEXT NOT NULL,                 -- 内容指纹；附件变化必须影响 input_hash
    storage_uri  TEXT NOT NULL,                 -- 对象存储/本地路径，不存二进制
    created_at   TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_case_attachments_review ON case_attachments (review_id);

-- ───────────── 模型调用存档 ─────────────
CREATE TABLE model_runs (
    id                UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    review_id         UUID NOT NULL REFERENCES review_jobs(id) ON DELETE CASCADE,
    role              TEXT NOT NULL,        -- chief_blind|jury_a|jury_b|vote|arbitration|preprocess
    provider          TEXT,                 -- qwen|deepseek|kimi
    model             TEXT NOT NULL,        -- 逻辑模型标识（配置项，如 qwen-max / deepseek-flash）
    requested_model   TEXT,                 -- 本次请求真正发出的 model 字段（厂商要求的 ID 或别名）
    model_version     TEXT,                 -- API 响应返回的版本（若有）
    prompt_version    TEXT,
    attempt           INT  NOT NULL DEFAULT 1,
    status            TEXT NOT NULL,        -- ok|timeout|error|parse_error
    request_tokens    INT,
    response_tokens   INT,
    latency_ms        INT,
    raw_request       JSONB,                -- 完整请求（含 messages），内部可读
    raw_response      JSONB,                -- 完整响应
    parsed_output     JSONB,                -- 解析后的结构化输出
    parse_warnings    JSONB NOT NULL DEFAULT '[]',
    cost_estimate     NUMERIC(12,4),        -- 按 price_config_version 估算
    cost_currency     TEXT DEFAULT 'CNY',
    price_config_version TEXT,
    error             TEXT,
    created_at        TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_model_runs_review ON model_runs (review_id, role);
CREATE INDEX idx_model_runs_cost   ON model_runs (review_id, cost_estimate);

-- ───────────── 阶段 Checkpoint（恢复用） ─────────────
CREATE TABLE review_stages (
    id          BIGSERIAL PRIMARY KEY,
    review_id   UUID NOT NULL REFERENCES review_jobs(id) ON DELETE CASCADE,
    stage       TEXT NOT NULL,                 -- input_check|preprocess|kb_retrieve|blind_review|fusion|vote|arbitration|verdict|render
    status      TEXT NOT NULL DEFAULT 'pending', -- pending|running|succeeded|failed|skipped
    attempt     INT  NOT NULL DEFAULT 1,
    fencing_token BIGINT,                      -- 本次执行的租约令牌
    input_digest TEXT,                         -- 输入摘要；变化才重跑
    output_ref  TEXT,                          -- 指向 model_runs / candidates / report_json
    started_at  TIMESTAMPTZ,
    finished_at TIMESTAMPTZ,
    error       TEXT,
    UNIQUE (review_id, stage)
);

CREATE INDEX idx_review_stages_review ON review_stages (review_id, stage);

-- ───────────── 阶段执行历史（只追加，不覆盖） ─────────────
CREATE TABLE review_stage_attempts (
    id             BIGSERIAL PRIMARY KEY,
    review_id      UUID NOT NULL REFERENCES review_jobs(id) ON DELETE CASCADE,
    stage          TEXT NOT NULL,
    attempt_no     INT  NOT NULL,
    fencing_token  BIGINT,
    status         TEXT NOT NULL,              -- running|succeeded|failed|skipped
    input_digest   TEXT,
    output_ref     TEXT,
    started_at     TIMESTAMPTZ,
    finished_at    TIMESTAMPTZ,
    error_code     TEXT,
    error_message  TEXT,
    worker_id      TEXT,
    model_run_id   UUID REFERENCES model_runs(id),
    created_at     TIMESTAMPTZ NOT NULL DEFAULT now(),

    UNIQUE (review_id, stage, attempt_no)
);

CREATE INDEX idx_stage_attempts_review ON review_stage_attempts (review_id, stage, attempt_no);

-- ───────────── 候选问题（融合产物，仲裁前中间数据） ─────────────
CREATE TABLE review_candidates (
    id                UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    review_id         UUID NOT NULL REFERENCES review_jobs(id) ON DELETE CASCADE,
    candidate_no      INT  NOT NULL,                  -- C-001
    step_index        INT,
    dimension         TEXT NOT NULL,
    severity_proposal TEXT,                           -- 融合阶段的建议级别（不是最终值）
    standardized_text TEXT NOT NULL,                  -- 中性标准化描述（投票材料，不含严重级倾向）
    claims            JSONB NOT NULL DEFAULT '[]',    -- [{claim_id, claim_text, claim_role:core|supporting, relation:and|or, evidence_refs, evidence_status}]
    evidence_status   TEXT NOT NULL DEFAULT 'insufficient', -- grounded|partially_grounded|ungrounded|conflicted|insufficient
    vote_valid_count  INT  NOT NULL DEFAULT 0,         -- 有效投票数（结构化且非失败）
    vote_completeness TEXT,                            -- "3/3"|"2/3"|"1/3"
    evidence_refs     JSONB NOT NULL DEFAULT '[]',
    proposed_by       JSONB NOT NULL DEFAULT '[]',    -- 仅内部留痕，不下发投票
    merged_from       JSONB NOT NULL DEFAULT '[]',
    fusion_basis      JSONB,
    status            TEXT NOT NULL DEFAULT 'candidate', -- candidate|disputed|merged
    created_at        TIMESTAMPTZ NOT NULL DEFAULT now(),

    UNIQUE (review_id, candidate_no),
    UNIQUE (id, review_id)                            -- 供 issue_votes / issues 复合外键
);

CREATE INDEX idx_review_candidates_review ON review_candidates (review_id, candidate_no);

-- ───────────── 问题条目（最终报告的只读投影，不是事实源） ─────────────
CREATE TABLE issues (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    review_id       UUID NOT NULL REFERENCES review_jobs(id) ON DELETE CASCADE,
    candidate_id    UUID,                             -- 来源候选（复合外键见下方 ALTER）
    issue_no        INT  NOT NULL,                    -- 报告内的 ISSUE-001 编号
    step_index      INT,                              -- null = 用例级
    step_tolerance  INT  NOT NULL DEFAULT 1,          -- 融合时的邻步容差
    dimension       TEXT NOT NULL,                    -- business|test_design|automation
    severity        TEXT NOT NULL,                    -- blocker|major|suggestion
    category        TEXT NOT NULL,
    evidence_quote  TEXT,
    rationale       TEXT NOT NULL,
    suggestion      TEXT,
    kb_grounded     BOOLEAN NOT NULL DEFAULT FALSE,
    kb_refs         JSONB NOT NULL DEFAULT '[]',      -- ["RULE-DIG-012","chunk:8842"]
    evidence_refs   JSONB NOT NULL DEFAULT '[]',      -- [{ref, source_ref, heading_path, doc_type, evidence_type, evidence_strength, ...}]
    evidence_type   TEXT,                             -- business_rule|requirement|known_limit|historical_bug|testing_standard|inference
    evidence_strength TEXT,                           -- strong|medium|weak
    evidence_status TEXT,                             -- grounded|partially_grounded|ungrounded|conflicted|insufficient
    proposed_by     JSONB NOT NULL DEFAULT '[]',      -- ["chief_blind","jury_a"]
    merged_from     JSONB NOT NULL DEFAULT '[]',      -- [{"reviewer":"jury_a","text":"原始问题摘要","step_index":3}]
    fusion_basis    JSONB,                            -- {"bucket":"...","max_cosine":0.93,"rerank_score":0.88,"rule":"same_root_cause"}

    -- 投票计数（冗余字段，便于统计与排序；明细见 issue_votes）
    support_count       INT NOT NULL DEFAULT 0,
    reject_count        INT NOT NULL DEFAULT 0,
    not_assessed_count  INT NOT NULL DEFAULT 0,
    uncertain_count     INT NOT NULL DEFAULT 0,
    support_ratio       NUMERIC(3,2),
    severity_distribution JSONB NOT NULL DEFAULT '{}', -- {"blocker":2,"major":1,"suggestion":0}

    confidence          NUMERIC(3,2),                 -- 校准后才有值；未校准为 NULL
    confidence_source   TEXT NOT NULL DEFAULT 'uncalibrated', -- uncalibrated|calibrated

    status          TEXT NOT NULL,                    -- adopted|rejected|disputed|need_human|chief_supplement
    chief_decision  TEXT,                             -- adopt|reject|dispute|need_human|supplement
    chief_reason    TEXT,                             -- 驳回/补充理由，必填
    human_verdict   TEXT,                             -- adopt|reject|missed（复核回写）
    human_note      TEXT,
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now(),

    UNIQUE (review_id, issue_no),
    UNIQUE (id, review_id),
    UNIQUE (review_id, candidate_id)
);

CREATE INDEX idx_issues_review   ON issues (review_id);
CREATE INDEX idx_issues_severity ON issues (severity, status);
CREATE INDEX idx_issues_human    ON issues (human_verdict);

ALTER TABLE issues
    ADD CONSTRAINT fk_issue_candidate_review
    FOREIGN KEY (candidate_id, review_id)
    REFERENCES review_candidates (id, review_id);

-- ───────────── 每个模型对每个候选问题的投票事实 ─────────────
CREATE TABLE issue_votes (
    id                  BIGSERIAL PRIMARY KEY,
    candidate_id        UUID NOT NULL,               -- 复合外键见下方 ALTER
    issue_id            UUID REFERENCES issues(id),  -- 最终投影回填（可空）
    review_id           UUID NOT NULL,
    model_run_id        UUID NOT NULL REFERENCES model_runs(id), -- 投票由哪一次模型调用产生
    reviewer_id         TEXT NOT NULL,      -- 评审角色：chief_blind|jury_a|jury_b
    validity            TEXT NOT NULL,      -- accept|reject|not_assessed|uncertain（问题是否成立）
    severity            TEXT,               -- blocker|major|suggestion（独立判断；validity!=accept 时可为空）
    reason              TEXT,
    evidence_refs       JSONB NOT NULL DEFAULT '[]',
    created_at          TIMESTAMPTZ NOT NULL DEFAULT now(),

    UNIQUE (candidate_id, reviewer_id)
);

CREATE INDEX idx_issue_votes_review ON issue_votes (review_id, validity);
CREATE INDEX idx_issue_votes_run    ON issue_votes (model_run_id);
CREATE INDEX idx_issue_votes_candidate ON issue_votes (candidate_id);

ALTER TABLE issue_votes
    ADD CONSTRAINT fk_vote_candidate_review
    FOREIGN KEY (candidate_id, review_id)
    REFERENCES review_candidates (id, review_id)
    ON DELETE CASCADE;

-- ───────────── Embedding Profile（向量由谁生成） ─────────────
CREATE TABLE embedding_profiles (
    id              BIGSERIAL PRIMARY KEY,
    provider        TEXT NOT NULL,          -- qwen|local
    model           TEXT NOT NULL,
    model_version   TEXT,
    dimension       INT  NOT NULL,
    similarity_metric TEXT NOT NULL DEFAULT 'cosine',
    normalize       BOOLEAN NOT NULL DEFAULT TRUE,
    config_version  TEXT NOT NULL,
    text_template_version TEXT,             -- 向量文本构造模板版本
    status          TEXT NOT NULL DEFAULT 'active',  -- active|candidate|retired
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now(),

    UNIQUE (provider, model, model_version, dimension, config_version),

    -- v1 固定 1024 维；多维度需另行设计分表/分列（见 docs/11 §4）
    CONSTRAINT v1_dimension_fixed CHECK (dimension = 1024)
);

ALTER TABLE review_jobs
    ADD CONSTRAINT fk_review_jobs_embedding_profile
    FOREIGN KEY (embedding_profile_id) REFERENCES embedding_profiles(id);

-- ───────────── Reranker Profile（版本与参数冻结） ─────────────
CREATE TABLE reranker_profiles (
    id              BIGSERIAL PRIMARY KEY,
    provider        TEXT NOT NULL,
    model           TEXT NOT NULL,
    model_version   TEXT,
    max_length      INT,
    score_threshold NUMERIC(4,3),
    input_template_version TEXT,
    config_version  TEXT NOT NULL,
    status          TEXT NOT NULL DEFAULT 'active',
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now(),

    UNIQUE (provider, model, model_version, config_version)
);

ALTER TABLE review_jobs
    ADD CONSTRAINT fk_review_jobs_reranker_profile
    FOREIGN KEY (reranker_profile_id) REFERENCES reranker_profiles(id);

-- ───────────── 问题向量（用于同义合并与历史检索） ─────────────
CREATE TABLE issue_embeddings (
    issue_id             UUID PRIMARY KEY REFERENCES issues(id) ON DELETE CASCADE,
    review_id            UUID NOT NULL,
    content              TEXT NOT NULL,           -- 用于生成向量的文本（rationale + evidence_quote）
    embedding_profile_id BIGINT NOT NULL REFERENCES embedding_profiles(id),
    embedding            vector(1024) NOT NULL    -- 维度与 profile 绑定；换维度需迁移
);

CREATE INDEX idx_issue_embeddings_ivf
    ON issue_embeddings USING ivfflat (embedding vector_cosine_ops) WITH (lists = 100);

-- ───────────── 候选问题向量（融合/投票前需要，早于最终 issues） ─────────────
CREATE TABLE candidate_embeddings (
    candidate_id         UUID NOT NULL,           -- 复合外键见下方
    review_id            UUID NOT NULL,
    content              TEXT NOT NULL,           -- standardized_text + claim_text（不含严重级倾向）
    embedding_profile_id BIGINT NOT NULL REFERENCES embedding_profiles(id),
    embedding            vector(1024) NOT NULL,
    created_at           TIMESTAMPTZ NOT NULL DEFAULT now(),

    PRIMARY KEY (candidate_id, embedding_profile_id),
    FOREIGN KEY (candidate_id, review_id)
        REFERENCES review_candidates (id, review_id) ON DELETE CASCADE
);

CREATE INDEX idx_candidate_embeddings_ivf
    ON candidate_embeddings USING ivfflat (embedding vector_cosine_ops) WITH (lists = 100);
CREATE INDEX idx_candidate_embeddings_profile ON candidate_embeddings (embedding_profile_id);

-- ───────────── 人工复核回写（issue 级事实，不等于审批） ─────────────
CREATE TABLE human_feedback (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    review_id       UUID NOT NULL REFERENCES review_jobs(id) ON DELETE CASCADE,
    issue_id        UUID REFERENCES issues(id),     -- null = 漏检项/整报告反馈
    verdict         TEXT NOT NULL,                 -- adopted|rejected|missed
    note            TEXT,
    reviewer        TEXT,
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_human_feedback_review ON human_feedback (review_id);

ALTER TABLE human_feedback
    ADD CONSTRAINT fk_feedback_issue_review
    FOREIGN KEY (issue_id, review_id)
    REFERENCES issues (id, review_id);

-- ───────────── 人工决定（报告级，append-only 事件，见 docs/09） ─────────────
CREATE TABLE review_decisions (
    id                    UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    review_id             UUID NOT NULL REFERENCES review_jobs(id) ON DELETE CASCADE,
    decision_no           BIGSERIAL,                -- 全局递增（隐含 NOT NULL），用于确定"当前有效决定"
    decision              TEXT NOT NULL,            -- approve|reject|request_changes
    reviewer_id           TEXT NOT NULL,            -- 审批人（服务端身份，不取客户端头）
    reason                TEXT,                     -- reject / request_changes 必填
    previous_verdict      TEXT,                     -- 决定前的 ai_verdict 快照
    previous_human_status TEXT,                     -- 决定前的 human_status 快照
    report_schema_version TEXT NOT NULL,            -- 决定针对的报告结构版本
    created_at            TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_review_decisions_review ON review_decisions (review_id, decision_no DESC);

-- ───────────── Webhook 投递记录 ─────────────
CREATE TABLE webhook_deliveries (
    id               BIGSERIAL PRIMARY KEY,
    review_id        UUID NOT NULL REFERENCES review_jobs(id) ON DELETE CASCADE,
    event            TEXT NOT NULL,             -- done|completed_with_warnings|failed
    generation       INT  NOT NULL,
    url              TEXT NOT NULL,
    status           TEXT NOT NULL DEFAULT 'pending', -- pending|delivered|failed
    attempts         INT  NOT NULL DEFAULT 0,
    last_status_code INT,
    last_error       TEXT,
    next_attempt_at  TIMESTAMPTZ,
    created_at       TIMESTAMPTZ NOT NULL DEFAULT now(),
```

## 3. 关键设计说明

1. **幂等 = 输入哈希 + 版本组合 + 代次**：`input_hash` 覆盖规范化后的 `case`（含附件 SHA-256）、`test_scope`、`automation_context` 与影响结论的 `options`（如 `strict_kb`）；`idempotency_key = sha256(input_hash + kb_version + rubric_version + prompt_version_hash + embedding_profile_id + retrieval_config_version + model_config_version)`。同一 key 同一时刻只允许一个 `superseded_by IS NULL` 的 active 记录（部分唯一索引），避免可空字段导致唯一约束失效。
2. **强制重跑 = 新代次，不是覆盖**：`force=true` 时在事务内把旧记录 `superseded_by` 指向新记录、写入 `parent_review_id`、`generation+1` 后插入；历史报告、审计与引用全部保留。并发重复请求由部分唯一索引兜底，冲突返回已有报告或 409。
3. **`review_jobs` 同时是任务队列**：`status + lease_expires_at` 支撑 `FOR UPDATE SKIP LOCKED` 领取与崩溃恢复；`queued/processing/retrying` 才进入队列索引，避免扫历史数据。
4. **AI 结论与人工决定分离**：`ai_verdict` 只由服务端计算，永不为 `approved`；`human_status` 由 `review_decisions` 中 `decision_no` 最大的一条派生；`review_decisions` 只 INSERT，不 UPDATE/DELETE，也不用 `superseded_by` 指针（见 `docs/09` §4）。
5. **`model_runs` 存全量原文与成本**：复盘、调优、标注的唯一依据；`requested_model` 与 `model_version` 分开，发现"配置别名"与"厂商实际版本"偏差；`cost_estimate + price_config_version` 让成本可解释。
6. **投票挂在候选上，不挂在最终问题上**：`issue_votes.candidate_id → review_candidates`；投票发生在仲裁前，此时最终 `issues` 还未生成。仲裁后 `issues` 通过 `candidate_id` 回链候选，`issue_votes.issue_id` 仅供投影回填，可为空。
7. **融合必须留痕**：`merged_from` 记录被合并的原始问题，`fusion_basis` 记录分桶键、最高余弦、rerank 分数与判定规则；否则无法排查"错误合并/漏合并/漏报"。
8. **`not_assessed` 必须落库**：未提及不等于反对；只存"支持/反对"无法区分"两方反对"与"一方反对、一方没说话"。
9. **置信度允许为空**：未校准前 `confidence=NULL`、`confidence_source=uncalibrated`，报告展示 `support_ratio` 与计数，不伪造小数点。
10. **`issues` 用 `issue_no` 对外展示**：报告里 `ISSUE-001` 可读、可引用、稳定。
11. **证据类型与强度必须落库**：`evidence_type`（`business_rule` / `requirement` / `known_limit` / `historical_bug` / `testing_standard` / `inference`）与 `evidence_strength`（`strong` / `medium` / `weak`）决定结论能用多强；历史缺陷不得表述为当前缺陷（见 `docs/04` §7）。
12. **`evidence_refs` 与 `kb_refs` 分工**：`kb_refs` 供人读（RULE-ID / 文档 ID），`evidence_refs` 供机器追溯（chunk_id、source_ref、heading_path、检索通道、rerank 分数、证据类型）。
13. **报告 JSON 是唯一事实源**：`report_json` 落完整结构，Markdown 只按 `report_schema_version` 渲染；禁止 JSON 与 Markdown 各维护一套内容。
14. **知识库按 `kb_version` 快照存储**：`kb_versions` 记录版本状态与检索指标，`active` 唯一；报告引用的 `kb_refs` 永远能回查到当时的规则原文。
15. **`kb_chunks` 的溯源字段是硬要求**：切片后不能只剩正文——规则 ID、适用范围、前置条件、原文位置必须绑在同一行。
16. **切片粒度按知识类型**：一条规则 / 一个功能点 / 一条已知限制 / 一个历史缺陷 / 一个术语 / 一个完整流程，各自一个 chunk；不按固定字符数硬切。
17. **v1 固定 1024 维**：`embedding_profiles.dimension` 有 `CHECK (dimension = 1024)`；换模型 = 新 profile + 重建索引 + 检索回归，禁止混用不同 profile 的向量。多维度并存需分表/分列，不在 v1 范围。18. **中文关键词检索有明确实现**：`pg_trgm` 三元组索引 + RULE-ID/字段/数值精确匹配；`zhparser` 是可选升级，安装后才改 `search_vector` 生成配置并重建（见 `docs/11` §5）。
19. **`human_verdict` 与 `human_feedback` 双写**：`issues.human_verdict` 是便捷冗余字段；`human_feedback` 是 issue 级审计流水，不等于报告审批（审批见 `review_decisions`）。
20. **`kb_gaps` 是知识库的生长机制**：`occurrences` 排序即可看出优先该补哪些规则。
21. **成立性与严重级分开**：`issue_votes.validity` 只回答"问题是否成立"，`severity` 单独回答"多严重"；`issues.severity` 是服务端按票与仲裁算出的终值，`severity_distribution` 保留分布，原始投票不覆盖。
22. **`report_json` 是唯一事实源，`issues` 是只读投影**：两者同事务写入；支持从 `report_json` 重建 `issues` 与 Markdown；人工审批只追加，不修改投影中的 AI 原始结论（见 §3 第 13 条与 `docs/09`）。
23. **`review_completeness` 记录评审完整性**：哪些阶段完成、几方参与、是否仲裁；2/3 与 3/3 必须可区分，1/3 不出正式 AI 结论。
24. **证据分级 E1–E4**：与 `evidence_type` 对应（E1 权威规则、E2 需求/功能、E3 测试规范、E4 推断）；`valid_from/to_version` 与 `applicable_conditions` 表达适用范围；同级规则冲突一律转 `need_human`。
25. **`timings` 记录阶段耗时**：排队、执行、模型调用分开，避免把"端到端 120s"与"模型超时 120s"混为一谈。
26. **Prompt 有注册表**：`prompt_registry` 记录阶段、版本、输入/输出 Schema、模型角色、是否允许重试与变更说明，API 与文档不再各自维护阶段清单。
27. **候选与最终问题分离**：`review_candidates` 是仲裁前中间数据；`issues` 是仲裁后从 `report_json` 派生的只读投影。禁止让 `issues` 同时承担"候选"和"最终问题"两种职责。
28. **人工决定是事件，不是可变状态**：只用 `decision_no` 递增确定当前有效决定；不更新历史记录，也不需要 `superseded_by`。
29. **generation 有父子链**：新代次记录 `parent_review_id`，可查询同一用例的完整评审历史；旧报告与审批历史不被覆盖。
30. **角色由服务端身份推导**：审批人/提交人来自 API Key 映射，不信任客户端 `X-Role`；`admin` 与 `approver` 分离，系统管理权限不自动包含报告审批。
31. **`case_version` 与 `generation` 分开**：`case_version` 表示用例内容版本，`generation` 表示同一输入的评审代次；修改用例产生新 `case_version`，强制重跑产生新 `generation`。
32. **候选向量独立存储**：`candidate_embeddings` 在融合/投票前写入，早于最终 `issues`；`issue_embeddings` 只服务最终问题，二者不混用。
33. **证据按 claim 绑定**：`review_candidates.claims` 保留每个主张及其证据；`evidence_status` 由 claim 汇总，融合不得把 A 的证据算到 B 的主张上。
34. **阶段 Checkpoint**：`review_stages` 记录每阶段状态与输出引用；重试从最后成功阶段恢复，已成功阶段不重跑。
35. **报告生成即锁定**：`report_locked_at` 非空后 `report_json` 不可更新；更正只能新建 generation（见 `docs/14` §7）。
36. **阶段历史不只保留当前态**：`review_stages` 存当前状态，`review_stage_attempts` 存每次尝试；恢复时按 attempt 与 `input_digest` 判断能否复用。
37. **版本在任务创建时冻结**：`kb/rubric/prompt/model/retrieval/embedding/reranker` 版本写入 `review_jobs`；恢复不得切到新版本（见 `docs/22`）。
38. **候选投票完整性独立统计**：`review_candidates.vote_valid_count` / `vote_completeness` 与全局 `review_completeness` 分开；每条候选独立计算有效票。
39. **Profile 兼容性**：`embedding_profiles` 增加 `text_template_version`，`reranker_profiles` 独立管理；不同 profile 的向量即使同维也不比较。
40. **枚举与 CHECK**：状态/枚举按 `docs/17` 统一，数据库对关键状态加 CHECK；JSONB 结构由应用层 Schema 校验。
