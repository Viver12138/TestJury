# 02 · 数据模型

数据库：PostgreSQL 15+，扩展 `pgvector`。

## 1. 实体关系

```
batches 1 ── n review_jobs
review_jobs 1 ── n model_runs        （3 次盲评 + 1 次仲裁 + 可能的重试）
review_jobs 1 ── n issues
issues 1 ── 1 issue_embeddings
issues 1 ── n human_feedback
kb_documents / kb_rules  ──  被报告通过 kb_refs 引用（逻辑引用，不建外键）
kb_gaps  ──  由评审中的"无依据判断"聚合产生
```

## 2. DDL

```sql
CREATE EXTENSION IF NOT EXISTS vector;
CREATE EXTENSION IF NOT EXISTS pgcrypto;

-- ───────────── 批次 ─────────────
CREATE TABLE batches (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    status          TEXT NOT NULL DEFAULT 'queued',   -- queued|processing|done|partial|failed
    total           INT  NOT NULL DEFAULT 0,
    done            INT  NOT NULL DEFAULT 0,
    failed          INT  NOT NULL DEFAULT 0,
    caller_id       TEXT,
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now(),
    finished_at     TIMESTAMPTZ
);

-- ───────────── 评审任务 ─────────────
CREATE TABLE review_jobs (
    id                  UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    batch_id            UUID REFERENCES batches(id),
    case_id             TEXT NOT NULL,
    case_title          TEXT,
    module              TEXT,                        -- 规范化后的模块名；未命中知识库时仍记录原值
    status              TEXT NOT NULL DEFAULT 'queued', -- queued|processing|done|failed
    stage               TEXT,                        -- preprocess|kb_retrieve|blind_review|fusion|arbitration|render
    verdict             TEXT,                        -- blocked|conditional|need_human|approved(仅人工)
    human_approved_by   TEXT,
    degraded            BOOLEAN NOT NULL DEFAULT FALSE,
    degraded_reasons    JSONB NOT NULL DEFAULT '[]',  -- ["kb_module_missing","raw_text_unparsed","model_missing"]
    participants        JSONB NOT NULL DEFAULT '[]',  -- ["chief:qwen-max","jury_a:deepseek-flash",...]
    kb_version          TEXT,
    rubric_version      TEXT,
    input_hash          TEXT NOT NULL,
    request_payload     JSONB NOT NULL,               -- 原始请求体
    normalized_case     JSONB,                        -- 规范化后的用例（含预处理拆分的 steps）
    report_summary      JSONB,                        -- 报告摘要
    error               TEXT,
    created_at          TIMESTAMPTZ NOT NULL DEFAULT now(),
    started_at          TIMESTAMPTZ,
    finished_at         TIMESTAMPTZ,

    UNIQUE (case_id, input_hash, kb_version, rubric_version)
);

CREATE INDEX idx_review_jobs_case    ON review_jobs (case_id, created_at DESC);
CREATE INDEX idx_review_jobs_module  ON review_jobs (module, created_at DESC);
CREATE INDEX idx_review_jobs_verdict ON review_jobs (verdict, created_at DESC);
CREATE INDEX idx_review_jobs_batch   ON review_jobs (batch_id);

-- ───────────── 模型调用存档 ─────────────
CREATE TABLE model_runs (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    review_id       UUID NOT NULL REFERENCES review_jobs(id) ON DELETE CASCADE,
    role            TEXT NOT NULL,        -- chief_blind|jury_a|jury_b|arbitration|preprocess
    model           TEXT NOT NULL,        -- qwen-max / deepseek-flash / kimi-k3 / <preprocess model>
    model_version   TEXT,
    prompt_version  TEXT,
    attempt         INT  NOT NULL DEFAULT 1,
    status          TEXT NOT NULL,        -- ok|timeout|error|parse_error
    request_tokens  INT,
    response_tokens INT,
    latency_ms      INT,
    raw_request     JSONB,                -- 完整请求（含 messages），内部可读
    raw_response    JSONB,                -- 完整响应
    parsed_output   JSONB,                -- 解析后的结构化输出
    parse_warnings  JSONB NOT NULL DEFAULT '[]',
    error           TEXT,
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_model_runs_review ON model_runs (review_id, role);

-- ───────────── 问题条目 ─────────────
CREATE TABLE issues (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    review_id       UUID NOT NULL REFERENCES review_jobs(id) ON DELETE CASCADE,
    issue_no        INT  NOT NULL,                    -- 报告内的 ISSUE-001 编号
    step_index      INT,                              -- null = 用例级
    step_tolerance  INT  NOT NULL DEFAULT 1,          -- 融合时的邻步容差
    dimension       TEXT NOT NULL,                    -- business|test_design|automation
    severity        TEXT NOT NULL,                    -- blocker|major|suggestion
    category        TEXT NOT NULL,
    evidence_quote  TEXT,
    rationale       TEXT NOT NULL,
    suggestion      TEXT,
    kb_grounded     BOOLEAN NOT NULL DEFAULT FALSE,
    kb_refs         JSONB NOT NULL DEFAULT '[]',      -- ["RULE-DIG-012"]
    proposed_by     JSONB NOT NULL DEFAULT '[]',      -- ["chief_blind","jury_a"]
    confidence      NUMERIC(3,2) NOT NULL DEFAULT 0.60,
    status          TEXT NOT NULL,                    -- adopted|rejected|disputed|need_human|chief_supplement
    chief_decision  TEXT,                             -- adopt|reject|supplement
    chief_reason    TEXT,                             -- 驳回/补充理由，必填
    human_verdict   TEXT,                             -- adopt|reject|missed（复核回写）
    human_note      TEXT,
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now(),

    UNIQUE (review_id, issue_no)
);

CREATE INDEX idx_issues_review   ON issues (review_id);
CREATE INDEX idx_issues_severity ON issues (severity, status);
CREATE INDEX idx_issues_human    ON issues (human_verdict);

-- ───────────── 问题向量（用于同义合并与历史检索） ─────────────
CREATE TABLE issue_embeddings (
    issue_id        UUID PRIMARY KEY REFERENCES issues(id) ON DELETE CASCADE,
    review_id       UUID NOT NULL,
    content         TEXT NOT NULL,                -- 用于生成向量的文本（rationale + evidence_quote）
    embedding       vector(1024) NOT NULL          -- 维度随 embedding 模型配置
);

CREATE INDEX idx_issue_embeddings_ivf
    ON issue_embeddings USING ivfflat (embedding vector_cosine_ops) WITH (lists = 100);

-- ───────────── 人工复核回写 ─────────────
CREATE TABLE human_feedback (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    review_id       UUID NOT NULL REFERENCES review_jobs(id) ON DELETE CASCADE,
    issue_id        UUID REFERENCES issues(id),     -- null = 针对整份报告的结论
    verdict         TEXT NOT NULL,                 -- adopted|rejected|missed
    note            TEXT,
    reviewer        TEXT,
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX idx_human_feedback_review ON human_feedback (review_id);

-- ───────────── 知识库 ─────────────
CREATE TABLE kb_documents (
    id              BIGSERIAL PRIMARY KEY,
    module          TEXT NOT NULL,
    doc_id          TEXT NOT NULL,
    title           TEXT NOT NULL,
    content         TEXT NOT NULL,
    doc_type        TEXT NOT NULL,                 -- requirement|design|gm_command|known_limit|history_bug|term
    source_ref      TEXT,                          -- 原始出处（文档名/章节）
    kb_version      TEXT NOT NULL,
    UNIQUE (doc_id, kb_version)
);

CREATE INDEX idx_kb_documents_module ON kb_documents (module, doc_type);

CREATE TABLE kb_rules (
    id              BIGSERIAL PRIMARY KEY,
    rule_id         TEXT NOT NULL,                 -- RULE-DIG-012
    module          TEXT NOT NULL,
    function_point  TEXT NOT NULL,
    rule_text       TEXT NOT NULL,
    source_ref      TEXT,
    kb_version      TEXT NOT NULL,
    UNIQUE (rule_id, kb_version)
);

CREATE INDEX idx_kb_rules_module ON kb_rules (module, function_point);

CREATE TABLE kb_chunks (
    id              BIGSERIAL PRIMARY KEY,
    doc_id          TEXT NOT NULL,
    module          TEXT NOT NULL,
    content         TEXT NOT NULL,
    embedding       vector(1024),
    kb_version      TEXT NOT NULL
);

CREATE INDEX idx_kb_chunks_ivf
    ON kb_chunks USING ivfflat (embedding vector_cosine_ops) WITH (lists = 100);

-- ───────────── 知识库缺口 ─────────────
CREATE TABLE kb_gaps (
    id              BIGSERIAL PRIMARY KEY,
    module          TEXT,
    function_point  TEXT,
    suspected_rule  TEXT NOT NULL,                 -- 被反复判断但知识库里找不到依据的规则
    examples        JSONB NOT NULL DEFAULT '[]',   -- 关联的 issue 文本样例
    occurrences     INT  NOT NULL DEFAULT 1,
    first_seen      TIMESTAMPTZ NOT NULL DEFAULT now(),
    last_seen       TIMESTAMPTZ NOT NULL DEFAULT now(),
    status          TEXT NOT NULL DEFAULT 'open',  -- open|accepted|dismissed|merged
    handled_by      TEXT,
    handled_at      TIMESTAMPTZ
);

CREATE INDEX idx_kb_gaps_status ON kb_gaps (status, occurrences DESC);
```

## 3. 关键设计说明

1. **`review_jobs` 的唯一约束是幂等键**：同用例、同输入、同知识库与 rubric 版本不会重复评审；要复跑必须带 `force=true`，此时插入新记录（旧记录保留，形成天然的历史对比）。
2. **`model_runs` 存全量原文**：这是复盘、调优、黄金集标注的唯一依据，比只存解析后结果重要得多。
3. **`issues` 用 `issue_no` 而不是 UUID 对外展示**：报告里 `ISSUE-001` 可读、可引用、稳定。
4. **`human_verdict` 与 `human_feedback` 双写**：`issues.human_verdict` 是便捷冗余字段，便于统计；`human_feedback` 是审计流水。
5. **知识库按 `kb_version` 快照存储**：不覆盖历史版本，报告引用的 `kb_refs` 永远能回查到当时的规则原文。
6. **`kb_gaps` 是知识库的生长机制**：`occurrences` 排序即可看出优先该补哪些规则。
