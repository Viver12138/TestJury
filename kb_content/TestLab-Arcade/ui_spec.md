# TestLab Arcade UI 前端设计规范 V1.0

## 1. 文档目的

本文档用于描述现有页面的布局、坐标、尺寸、间距、颜色、状态和响应式规则，作为 UI 验收与测试案例编写的依据。本文档不依据截图反推，也不提出改版方案。

适用范围：

1. 前端实现核对；
2. UI 验收；
3. 测试案例编写；
4. 后续版本在现有视觉基础上的维护。

## 2. 坐标与测量规则

### 2.1 基准画布

- 桌面端基准视口：`1440 × 900 px`；
- 坐标原点：浏览器内容视口左上角，记为 `(0, 0)`；
- `X` 向右增加，`Y` 向下增加；
- 页面滚动后的元素仍使用文档坐标描述；
- 坐标验收容差：普通布局 `±4 px`，文字自然排版高度 `±8 px`；
- 浏览器缩放应为 `100%`，系统显示缩放不作为 CSS 像素偏差判定依据。

### 2.2 页面容器公式

全站主容器按以下规则计算：

- 容器宽度取 `1400 px` 与“视口宽度减 `32 px`”两者中的较小值；
- 容器左坐标等于（视口宽度减容器宽度）除以 2。

在 `1440 px` 宽视口中：

- 容器宽度为 `1400 px`；
- 容器左坐标为 `20 px`；
- 容器右边界为 `1420 px`。

在小于 `1432 px` 的视口中，容器左右边距均为 `16 px`。

## 3. 全站视觉规范

### 3.1 色彩

| 名称 | 色值 | 用途 |
|---|---|---|
| 页面背景 | `#f4f2ec` | 全站底色 |
| 表面色 | `#fffdf8` | 面板、次级按钮 |
| 主文字 | `#1c211d` | 标题、正文、深色按钮 |
| 次文字 | `#667068` | 说明、辅助信息 |
| 分隔线 | `#d9ddd5` | 边框和分割线 |
| 强调色 | `#d76a3d` | 主按钮、游戏挡板 |
| 深强调色 | `#a84222` | 强调文字、悬停和焦点 |
| 成功色 | `#3f7254` | 成功状态预留 |
| 危险色 | `#a83b32` | 错误提示、退出按钮 |

页面背景由左上方浅橙色径向光晕和纵向浅色渐变组成。

### 3.2 字体

- 字体栈：`Arial, Microsoft YaHei, sans-serif`；
- 默认正文色：`#1c211d`；
- 常规正文：`16 px`；
- 辅助文字：`14 px`；
- 小标签：`12–14 px`，粗体；
- 页面主标题按页面类型使用 `36–72 px`；
- 标题采用负字距，正文采用正常字距。

### 3.3 面板

所有信息面板采用统一规则：

- 边框：`1 px` 半透明分隔线色；
- 圆角：`28 px`；
- 背景：约 92% 不透明的表面色；
- 阴影：`0 24px 70px rgba(39,45,39,0.08)`。

### 3.4 按钮

所有主按钮、次按钮和危险按钮：

- 最小高度：`44 px`；
- 水平内边距：`18 px`；
- 垂直内边距：`10 px`；
- 胶囊圆角：`999 px`；
- 图标与文字间距：`8 px`；
- 字重：`700`；
- 按下状态：整体缩放至 `98%`；
- 键盘焦点：`2 px #a84222` 外轮廓，偏移 `4 px`；
- 禁用状态：保留位置，不响应重复提交。

主按钮为橙色底、白字；悬停时变为深橙。次按钮为浅色底、灰色边框。危险按钮为透明底、危险色文字。

### 3.5 输入框

- 标签位于输入框上方；
- 标签与输入框间距：`8 px`；
- 输入框宽度：父容器 `100%`；
- 最小高度：`46 px`；
- 圆角：`14 px`；
- 内边距：上下 `10 px`、左右 `14 px`；
- 聚焦时边框改为强调色；
- 错误信息位于字段组下方，颜色为危险色，字号 `14 px`。

## 4. 全局页头

### 4.1 桌面端布局

基准视口 `1440 × 900`：

| 元素 | 坐标或范围 | 尺寸/规则 |
|---|---|---|
| 页头容器 | `(20, 0)` | `1400 × 80 px`，底部 `1 px` 分隔线 |
| 品牌入口 | 左对齐，垂直居中 | 高度约 `36 px` |
| TL 标志 | `(20, 22)` | `36 × 36 px`，圆角 `12 px` |
| 品牌文字 | 标志右侧 `12 px` | 粗体，单行 |
| 主导航 | 靠右，垂直居中 | 横向排列，间距 `8 px` |
| 控制台入口 | 导航第1项 | 内边距 `12 × 8 px` |
| 弹球实验入口 | 导航第2项 | 内边距 `12 × 8 px` |

页头所有页面共用。页头固定高度但不吸顶，页面滚动时随文档离开视口。

### 4.2 窄屏规则

- 容器左右保留 `16 px`；
- 品牌和导航仍保持同一行；
- 导航文字较长时以自然宽度占位，不另设汉堡菜单；
- 当前实现没有移动端折叠菜单，因此 `320 px` 左右窄屏可能较拥挤，属于现版已知限制。

## 5. 公共首页 `/`

### 5.1 桌面端结构

页面主区域从 `Y=80` 开始，顶部内边距 `64 px`，即主要内容起始约为 `Y=144`。主区域最小高度为视口高度减去页头 `80 px`。

主内容为两列网格：

```text
列比例：1.25fr : 0.75fr
列间距：48 px
总可用宽度：1400 px
左列约：845 px
右列约：507 px
```

| 元素 | 参考位置 | 规则 |
|---|---|---|
| 左侧文案区 | `(20, 144)` | 最大宽度 `768 px` |
| 阶段标签 | 左侧文案区顶部 | `14 px`、粗体、大写字距 |
| 主标题 | 标签下方 `20 px` | 桌面 `72 px`，两行，行高约 `0.98` |
| 说明正文 | 标题下方 `28 px` | `18 px`，最大宽度 `62ch`，行高 `32 px` |
| CTA 按钮组 | 正文下方 `36 px` | 横向换行排列，间距 `12 px` |
| 创建账号 | 按钮组第1项 | 主按钮，含右箭头 |
| 登录 | 按钮组第2项 | 次按钮 |
| 功能面板 | 右列起点，垂直居中 | 内边距桌面 `36 px` |
| 功能列表 | 面板标题下方 `24 px` | 3项，项目之间使用分隔线 |
| 功能图标 | 每项左侧 | `44 × 44 px`，圆角 `16 px` |

功能面板右上角有一个直径 `192 px` 的半透明强调色装饰圆，超出面板部分被裁切，不响应操作。

### 5.2 响应式

- `<1024 px`：两列改为单列；功能面板排列在文案区下方；
- `<768 px`：页面上下内边距由 `64 px` 降为 `40 px`；主标题从 `72 px` 降为 `48 px`；面板内边距由 `36 px` 降为 `28 px`；
- CTA 允许换行，按钮不强制等宽。

## 6. 登录页 `/login`

### 6.1 桌面端坐标

主区域在页头下方垂直和水平居中。认证面板最大宽度 `1024 px`，在 `1440 px` 视口中：

```text
面板 X = 208 px
面板宽度 = 1024 px
左栏宽度 ≈ 410 px
右栏宽度 ≈ 614 px
```

面板高度由内容决定，整体在可用的 `820 px` 高主区域中居中。上下至少保留 `40 px`。

| 元素 | 位置规则 | 尺寸/间距 |
|---|---|---|
| 左侧说明区 | 面板左侧 | 深色背景，桌面内边距 `48 px` |
| 产品标签 | 左栏顶部 | `14 px`、粗体、浅橙色 |
| 欢迎标题 | 标签下方 `24 px` | `36 px` 粗体 |
| 说明文字 | 标题下方 `20 px` | 最大宽度 `38ch`，行高 `28 px` |
| 右侧表单区 | 面板右侧 | 桌面内边距 `48 px` |
| 表单标题 | 右栏顶部 | `24 px` 粗体 |
| 表单说明 | 标题下方 `8 px` | `14 px` 次文字 |
| 表单 | 说明下方 `32 px` | 单列，字段组间距 `20 px` |
| 邮箱输入 | 表单第1项 | 高度至少 `46 px` |
| 密码输入 | 表单第2项 | 高度至少 `46 px` |
| 错误区 | 密码下方 | 最小高度 `20 px`，无错误时保留占位 |
| 登录按钮 | 错误区下方 | 宽度 `100%`，最小高度 `44 px` |
| 注册入口 | 表单下方 `28 px` | 文字链接带下划线 |

### 6.2 页面状态

- 默认：按钮文字为“登录并进入实验场”；
- 提交中：按钮图标为旋转加载符号，按钮禁用；
- 凭据错误：错误区显示通用错误，不说明邮箱是否存在；
- 服务异常：错误区显示稍后重试提示；
- 成功：跳转 `/dashboard`。

### 6.3 响应式

- `<1024 px`：认证面板由两列改为上下两段；
- `<768 px`：两区内边距由 `48 px` 改为 `32 px`；
- 面板宽度始终不超过主容器宽度。

## 7. 注册页 `/register`

注册页沿用登录页面板和坐标规则。差异如下：

1. 表单字段顺序为显示名称、邮箱、密码、确认密码；
2. 字段之间均为 `20 px` 间距；
3. 表单因字段增加而变高，面板保持内容自适应；
4. 提交按钮宽度 `100%`，文字为“创建账号”；
5. 两次密码不一致时，错误信息显示在按钮上方的固定错误区；
6. 成功后进入 `/dashboard`；
7. 底部提供“返回登录”文字入口。

当前现有实现没有服务条款复选框，不应在本版 UI 验收中要求出现。

## 8. 登录后主界面 `/dashboard`

### 8.1 标题区

页面从 `Y=80` 开始，桌面顶部内边距 `56 px`。标题区参考起点 `(20, 136)`，底部有分隔线。

| 元素 | 位置规则 | 尺寸/间距 |
|---|---|---|
| “用户控制台”标签 | 标题区左上 | `14 px`，深强调色 |
| 用户问候标题 | 标签下方 `8 px` | `36 px` 粗体 |
| 引导说明 | 标题下方 `12 px` | 次文字 |
| 开始游戏按钮 | 标题区右下 | 主按钮，含游戏手柄图标 |
| 标题区底边 | 内容下方 `32 px` | `1 px` 分隔线 |

### 8.2 概览区

标题区下方 `32 px`，两列比例 `1.25fr : 0.75fr`，列间距 `24 px`。

- 左侧“个人最高分”面板：桌面内边距 `36 px`；最高分数字 `48 px`；奖杯图标容器 `56 × 56 px`；
- 右侧“测试知识库”面板：桌面内边距 `36 px`；显示未开放说明和状态胶囊；
- 两块面板等高由网格自然拉伸。

### 8.3 最近记录区

- 与概览区间距：`32 px`；
- 区域标题左对齐；“个人中心”入口右对齐；
- 记录面板与标题间距：`20 px`；
- 空状态：面板内边距 `40 px`，图标和文字水平居中；
- 有记录：每条记录使用两列布局，内边距为水平 `24 px`、垂直 `16 px`；分数和时间在左，时长在右；记录间用分隔线区分。

### 8.4 响应式

- `<768 px`：标题区改为上下排列，开始游戏按钮位于标题文字下方；
- `<1024 px`：概览区改为单列；
- 页面顶部内边距在窄屏由 `56 px` 降为 `40 px`。

## 9. 三维弹球页 `/game`

### 9.1 页面标题

桌面端页面顶部内边距 `40 px`，标题区参考起点 `(20, 120)`：

- 分类标签：`14 px` 深强调色；
- 页面标题：标签下方 `8 px`，`30 px` 粗体；
- 游戏面板：标题区下方 `24 px`。

### 9.2 游戏面板

游戏面板占满主容器宽度，深色背景，桌面内边距 `20 px`，面板圆角 `28 px`。

内部网格：

```text
主画布宽度 = 剩余空间
侧栏宽度 = 250 px
画布与侧栏间距 = 12 px
```

在 `1440 px` 基准视口中，游戏面板外宽约 `1400 px`，扣除边框和内边距后，主画布约 `1096 px`，侧栏 `250 px`。

| 元素 | 位置/规则 | 尺寸 |
|---|---|---|
| 三维画布 | 面板左侧 | 最小高度 `620 px`，圆角 `24 px` |
| 信息侧栏 | 面板右侧 | `250 px`，纵向排列，间距 `12 px` |
| 当前分数卡 | 侧栏第1项 | 圆角 `24 px`，内边距 `20 px` |
| 分数数字 | 标签下方 `8 px` | `30 px`，深橙色 `#b94725` |
| 剩余弹球卡 | 侧栏第2项 | 同分数卡 |
| 弹球数字 | 标签下方 `8 px` | `30 px`，深绿色 `#263a30` |
| 操作说明卡 | 侧栏第3项 | 内边距 `20 px` |
| 操作行 | 卡内纵向排列 | 行间距 `12 px`，按键在右侧 |
| 控制按钮组 | 侧栏第4项 | 横向，间距 `8 px` |
| 暂停/继续 | 按钮组第1项 | 占据剩余宽度 |
| 音效开关 | 按钮组第2项 | 图标按钮，视觉宽度随内容 |
| 重新开始 | 按钮组第3项 | 图标按钮 |
| 状态消息 | 按钮组下方 | 左右内边距 `8 px`，`14 px` 字号 |

### 9.3 游戏启动遮罩

非“游戏中”和非“暂停”状态时，画布上方显示全覆盖遮罩：

- 坐标：相对画布 `(0, 0)`；
- 尺寸：画布 `100% × 100%`；
- 深色半透明背景并带轻微背景模糊；
- 内容水平、垂直居中；
- 文案最大宽度约 `384 px`；
- 启动按钮位于说明下方 `24 px`；
- 启动中或保存中按钮禁用。

### 9.4 游戏画布内部构图

三维画布中的视觉构图要求：

| 对象 | 构图要求 |
|---|---|
| 摄像机 | 从球台上方偏前侧俯视，视角稳定，游戏过程中不出现剧烈晃动 |
| 球台 | 完整显示在画布内，四周边界不被裁切 |
| 发射道 | 位于球台右侧，与球台主体连通 |
| 弹球 | 始终在球台范围内可见，不穿出边界 |
| 左右挡板 | 位于球台下部对称分布，中间留出落球缺口 |
| 得分柱 | 5个，分布于球台中上部 |

挡板安装位置固定，按键时只改变旋转角度；待机时两挡板向中央落球口倾斜，按键时快速向上挥击，松键后缓慢复位。

### 9.5 响应式和实际限制

- `<1024 px`：游戏画布和侧栏改为上下排列，侧栏宽度变为容器宽度；
- `<768 px`：游戏面板内边距由 `20 px` 降为 `12 px`；页面顶部内边距由 `40 px` 降为 `24 px`；
- 画布仍保持最小高度 `620 px`；
- 当前版本以桌面键盘为主要输入，没有移动端屏幕挡板按钮；
- 因此手机端仅保证页面不破版，不视为完整可玩体验。

## 11. 交互与可访问性

1. 所有按钮、链接和输入框必须可用键盘聚焦；
2. 聚焦态不得只依赖颜色变化，必须显示外轮廓；
3. 动态游戏消息使用礼貌播报区域；
4. 表单错误区使用警告语义；
5. 用户启用“减少动态效果”时，全站动画时长降至接近零；
6. 加载、错误、空数据、禁用和成功状态均保留原布局位置，避免页面明显跳动；
7. 图标按钮必须具有可读的辅助名称；
8. 主要交互目标高度不得低于 `44 px`。

## 12. UI 验收方法

### 12.1 固定坐标验收

适用于：页头高度、桌面主容器、登录面板宽度、游戏侧栏宽度、按钮最小高度、输入框最小高度等明确尺寸。

验收环境：

1. 浏览器视口设置为 `1440 × 900 px`；
2. 浏览器缩放设为 `100%`；
3. 页面滚动回顶部；
4. 字体加载完成；
5. 按本文档参考坐标和允许容差测量。

### 12.2 响应式验收

至少覆盖：

1. `1440 px`：完整桌面双列布局；
2. `1024 px` 临界点上下：检查首页、认证页、概览区和游戏区换列；
3. `768 px` 临界点上下：检查内边距、标题字号和标题区排列；
4. `640 px` 临界点上下：检查个人中心统计区；
5. `375 px`：检查页面无横向内容溢出；页头拥挤属于现版已知限制，应单独记录而非误判其他页面。

### 12.3 不应使用绝对坐标判错的内容

以下内容受文本、数据和字体渲染影响，应按相对位置和间距验收：

- 用户名和邮箱的文字终点；
- 错误信息换行后的高度；
- 最近记录数量增加后的页面高度；
- 不同分数位数造成的文字宽度；
- 浏览器对中文字形的细微基线差异。
