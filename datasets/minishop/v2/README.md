# MiniShop 黄金集 v2

由用户授权 AI 代理逐条复核的修订版，30 条正反用例，15 个场景族；原 v1 及其评测结果完整保留。

修订原因：v1 的支付重试正例声明“允许重试”，但没有重新创建支付单操作；其他样例中部分数据库副作用断言未给出读取步骤，支付记录与订单关联也不够明确。这些属于样例质量问题，不能统计为模型误报。

v2 补齐执行动作、查询方式和数据关联，删除运行步骤不能证明的全局源码性质断言，保留业务正反标签和场景族划分。`review_record.json` 记录逐条复核依据；修订没有把错误预期改成正确预期来迎合模型。

15 个业务事实已在归档 MiniShop 源码、固定依赖和独立 SQLite 数据库中验证，证据为 `evidence/M2/minishop_gold_source_verification.json`。测试使用身份注入，不包含 JWT 登录验证。业务事实验证不能替代评审效果验收。

来源、文件校验值见 `manifest.json`。v2 延续已见过的场景，不宣称新盲测或独立人工标注；服务反馈不会自动成为黄金标签。
