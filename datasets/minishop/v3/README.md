# MiniShop 黄金集 v3

当前工作版本，共30条评审用例和18条检索样例，均为用户授权AI代理编写并逐条技术复核。

v1发现支付重试正例未实际重试；v2补齐操作后，部分负例仍沿用旧的简短预期，额外引入了缺失断言。v3保留完整操作，为负例的每个观测点明确期望，只保留目标业务规则及其直接结果的错误。正例内容与v2一致。v1、v2及各轮模型原始结果不删除。

`review_record.json`包含30条复核记录，`manifest.json`固定文件校验值、原始源码版本和场景族划分。15个业务事实在冻结源码及独立SQLite数据库验证；身份认证使用fixture注入，见 `evidence/M2/minishop_gold_source_verification.json`。

这是已见过的种子场景迭代，不是新的盲测集或独立人工标注。模型诊断、代理复核和业务事实测试分别记录，不混合宣称生产效果达标。
